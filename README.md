# Практическая работа: параллельное тестирование (pytest + xdist + split)

**Выполнил:** Лисевич Арсений
**Группа:** Исп/п23-09.2
**Дисциплина:** Поддержка и тестирование программных модулей
**Число логических ядер:** 20

## Что внутри

| Файл / папка | Назначение |
|---|---|
| `tests/test_catalog.py` | 10 тестов по 0,5 с (имитация каталога) |
| `tests/test_orders.py` | 10 тестов по 1 с (имитация заказов) |
| `tests/test_reports.py` | 4 теста по 4 с (имитация построения отчётов) |
| `tests/test_profile.py` | 8 тестов с изоляцией через `tmp_path` (исправленный вариант) |
| `bug/test_profile.py` | исходный вариант с общим файлом `profile.json` — падает при `-n 4` |
| `.test_durations` | время каждого теста для разбиения `least_duration` |
| `logs/` | вывод всех прогонов, по нему собраны таблицы отчёта |
| `.github/workflows/tests.yml` | матрица CI: 4 job-а по одной части набора |

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

pytest -v --durations=5          # последовательно
pytest -n 2                      # 2 воркера
pytest -n 4                      # 4 воркера
pytest -n auto                   # по числу ядер
```

## Результаты

| Режим | Воркеров | Время, с | Ускорение | Эффективность |
|---|---|---|---|---|
| Последовательно | 1 | 31,07 | 1,00 | 1,00 |
| `-n 2` | 2 | 16,62 | 1,87 | 0,94 |
| `-n 4` | 4 | 8,77 | 3,54 | 0,89 |
| `-n auto` | 20 | 6,99 | 4,44 | 0,22 |

Sharding (`pytest-split`), общее время = самая медленная часть:

| Часть | Статическое: тестов / время | По длительности: тестов / время |
|---|---|---|
| 1 | 6 / 3,02 с | 6 / 7,52 с |
| 2 | 6 / 4,02 с | 6 / 8,02 с |
| 3 | 6 / 6,02 с | 6 / 7,52 с |
| 4 | 6 / 18,02 с | 6 / 8,02 с |
| **Итого (максимум)** | **18,02 с** | **8,02 с** |
